# 🦁 Bicharada

Jogo infantil para aprender o nome dos animais, feito para a educação infantil.

- **Categorias com 3 fases cada:** Mamíferos, Aves, Marinhos, Insetos e Répteis.
- **Jogo das Sombras:** a criança arrasta cada bicho até a sua sombra.
- **Voz em português**, que lê as perguntas, os nomes dos bichos e as letras.
- **Teclado colorido** para a criança escrever o próprio nome.
- **Estrelas** em cada fase. Elas são zeradas a cada novo jogador.
- Funciona no celular, no tablet e no computador, inclusive em tela cheia.

## Arquivos

| Arquivo | Para que serve |
|---|---|
| `index.html` | O jogo completo |
| `icon.svg` | O ícone do jogo |
| `manifest.webmanifest` | Permite instalar o jogo na tela inicial do tablet ou do celular |

## Como colocar o jogo no ar com o GitHub Pages (grátis)

### Etapa 1: Criar a conta
1. Acesse **github.com** e clique em **Sign up**.
2. Escolha um nome de usuário curto. Ele vai aparecer no endereço do jogo.

### Etapa 2: Criar o repositório
1. Clique no **+**, no canto superior direito, e depois em **New repository**.
2. Em **Repository name**, digite: `bicharada`
3. Marque a opção **Public**. O GitHub Pages grátis só funciona em repositórios públicos.
4. Clique em **Create repository**.

### Etapa 3: Enviar os arquivos
1. Na página do repositório, clique em **uploading an existing file** (ou em **Add file → Upload files**).
2. Arraste os 4 arquivos desta pasta: `index.html`, `icon.svg`, `manifest.webmanifest` e `README.md`.
3. Clique em **Commit changes**.

### Etapa 4: Ligar o GitHub Pages
1. No repositório, abra **Settings** e, no menu da esquerda, **Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Em **Branch**, escolha **main** e a pasta **/ (root)**. Depois clique em **Save**.
4. Espere de 1 a 3 minutos e recarregue a página. O endereço do jogo vai aparecer no topo:

   `https://SEU-USUARIO.github.io/bicharada/`

### Etapa 5: Testar
- Abra o endereço no computador, no celular e no tablet.
- Teste o som, a tela cheia, o teclado do nome, uma fase de cada grupo e o jogo das sombras.
- Se não ouvir a voz, confira se o volume está ligado e se o aparelho tem voz em português instalada.

### Etapa 6: Instalar no tablet da criança (opcional)
- **Android (Chrome):** abra o endereço, toque no menu **⋮** e depois em **Adicionar à tela inicial**.
- **iPhone ou iPad (Safari):** abra o endereço, toque em **Compartilhar** e depois em **Adicionar à Tela de Início**.

O jogo vira um ícone, como se fosse um aplicativo, e abre em tela cheia.

### Etapa 7: Compartilhar
- Envie o link para as famílias ou para a escola pelo WhatsApp ou por e-mail.
- Se quiser, gere um QR Code do link, por exemplo no site qr-code-generator.com, e imprima para a sala de aula.

### Etapa 8: Atualizar o jogo depois
1. No repositório, clique em **Add file → Upload files**.
2. Envie o novo `index.html`. Ele substitui o antigo.
3. Clique em **Commit changes**. Em cerca de 1 minuto, o site já está atualizado.
